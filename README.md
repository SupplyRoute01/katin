# 케이튼 (Katin)

캘리포니아 해안의 느린 리듬에서 영감을 받은 코듀로이 로컬 반바지 브랜드 사이트입니다.

## 로컬에서 보기

빌드 과정 없이 `index.html`을 브라우저에서 열면 됩니다. 간단한 로컬 서버가 필요하면 아래처럼 실행할 수 있습니다.

```bash
python3 -m http.server 8000
```

그 후 `http://localhost:8000`에 접속하세요.

## 파일 구성

- `index.html` — 전체 콘텐츠와 페이지 구조
- `styles.css` — 반응형 디자인과 애니메이션
- `script.js` — 모바일 메뉴, 제품 상세 창, 스크롤 효과
